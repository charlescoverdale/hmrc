# Deprecated get\_\* aliases

Renamed to use the `hmrc_*` prefix in v0.4.0. These aliases will be
removed in v0.6.0.

## Usage

``` r
get_tax_receipts(...)

get_vat(...)

get_fuel_duties(...)

get_tobacco_duties(...)

get_corporation_tax(...)

get_stamp_duty(...)

get_property_transactions(...)

get_rd_credits(...)

get_tax_gap(...)

get_income_tax_stats(...)

list_tax_heads()

clear_cache(max_age_days = NULL)
```
